# Shape Motion Generator

기본 도형과 SVG, 그리고 직접 쓴 카피를 섞어서 루프 애니메이션을 만드는 웹 도구예요.

## 여는 방법
1. 이 폴더에서 `index.html`을 **Chrome**으로 열어요. (파일 우클릭 → 다음으로 열기 → Google Chrome)
2. 설치할 것은 없어요. 인터넷이 연결돼 있으면 웹폰트도 같이 불러와요.

## 파일 구성
- `index.html` — 화면 구조
- `style.css` — Apple 기본 UI 스타일 (글래스 효과 없음)
- `app.js` — 그리는 로직, 움직임, 효과, 내보내기

## 기능 (첫 버전)
- 그래픽: 기본 도형 10종 추가, SVG 업로드(여러 개 가능), 레이어별 색·크기·개수, SVG 원본 색 유지
- 카피: 문구, 폰트(웹폰트 9종 + 내 폰트 파일), 굵기, 크기, 행간, 자간, 정렬, 위치(캔버스 드래그 가능), 색
- 배경: 단색 / 그라디언트(선형·원형, 각도) / 이미지 업로드
- 모션: 길이(1–20초), 반복 속도, 그래픽 움직임 7종, 카피 움직임 6종, 화면 효과 13종(메인 + 보조 2칸 겹치기, 추천 조합 랜덤), 겹침 방식(색 반전 등)
- 캔버스 비율: 16:9 · 6:4 · 3:4 · 4:5 · 9:16 · 1:1
- 내보내기: PNG(현재 프레임), 영상(MP4, 브라우저가 지원하지 않으면 WebM)

설정은 브라우저에 자동 저장돼요. 배경 이미지와 직접 불러온 폰트만 새로고침 후 다시 올려야 해요.
